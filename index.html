Natural Language → Bash

GitHub ↗ Model ↗ Demo ↗

Fine-tuned Llama-3.2-1B-Instruct and Qwen2.5-Coder-0.5B-Instruct on 40,639 natural-language-to-Bash command pairs, then built an evaluation and production inference layer around the models.

Exact string match undercounts correct commands — two different Bash commands can do the same thing. To measure this properly, I compared eight functional-equivalence heuristics across 600 hand-labeled command pairs. The best approach, execution-assisted embedding evaluation, reached 90% accuracy and a 0.89 F1 score.

The engineering layer wraps the models in a FastAPI service with single and batch (max 10) translation endpoints, health monitoring, latency logging, a 20-test pytest suite, and CI that runs on every push and pull request.

03
GEOSPATIAL ML · DATA SCIENCE

Urban Food Deserts

GitHub ↗ Dashboard ↗

Analyzed 1,314 Cook County census tracts, integrating USDA food-access data with demographic, income, broadband, SNAP, and transportation signals across 12 affordability and demographic features — including a custom Digital Barrier Index for broadband access.

Only 3.9% of tracts are labeled food deserts. I benchmarked logistic regression, random forest, gradient boosting, SVM, and naive Bayes, applying SMOTE to the training split only to avoid leakage. A balanced logistic regression model raised recall from 0% to 73% (0.804 ROC-AUC, 66.7% recall on its own), and the best model reached 0.825 ROC-AUC on the held-out test set (0.838 ± 0.026 across cross-validation).

04
RESPONSIBLE AI · DATA MINING · RESEARCH

FairLend

GitHub ↗

Audited mortgage-lending patterns across 103,481 HMDA 2023 applications using association-rule mining and fairness-aware binning: standard binning surfaced 819 frequent itemsets and 2,214 rules, while fairness-aware binning surfaced 854 itemsets and 2,454 rules. The strongest signal was high debt-to-income ratio (10.7% support, 67.2% confidence, 2.81 lift). No explicit demographic denial rules appeared above the 10% support threshold, so I followed up with clustering and cluster-level disparate-impact analysis to surface disparities the global rules missed.
